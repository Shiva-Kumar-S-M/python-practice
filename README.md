# 🐍 Python Practice

A structured repository for practicing Python — built around the **80/20 principle**: master the 20% of Python that unlocks 80% of real-world capability.

## 📌 About

This repo is my hands-on space to learn and practice core Python concepts through small scripts, exercises, and mini-projects — organized day by day for a focused 1-week sprint.

## 🗺️ 7-Day Roadmap — The 20% That Gives 80% of Python

> Goal: skip the long-tail trivia and drill the handful of concepts that show up in almost every real Python program (scripts, APIs, automation, data work).

| Day | Focus Area | Core Topics (the vital 20%) | Practice Goal |
|-----|-----------|------------------------------|----------------|
| **1** | Foundations | Variables, data types (`int`, `float`, `str`, `bool`), type casting, input/output, basic operators | Write 5 small scripts (calculator, temperature converter, etc.) |
| **2** | Control Flow | `if/elif/else`, `for` & `while` loops, `break`/`continue`, list comprehensions | Solve 10 logic problems (FizzBuzz, pattern printing, number games) |
| **3** | Functions | Defining functions, parameters, `*args`/`**kwargs`, return values, scope, lambda functions | Refactor Day 1–2 scripts into reusable functions |
| **4** | Data Structures | Lists, dictionaries, tuples, sets, string methods, slicing | Build a contact book / inventory tracker using dicts & lists |
| **5** | Object-Oriented Programming | Classes, objects, `__init__`, methods, inheritance, basic encapsulation | Model a real-world system (e.g., Library, Bank Account) as classes |
| **6** | Errors, Files & Modules | `try/except`, reading/writing files, importing modules, intro to `pip`/virtual environments | Build a script that reads a file, processes data, handles bad input gracefully |
| **7** | Capstone Project | Combine everything: functions + OOP + file handling + error handling | Build one complete mini-project (e.g., To-Do App, Expense Tracker, Quiz Game) |

### Why this order?
These seven areas cover the concepts that appear in the vast majority of everyday Python code — automation scripts, small tools, interview questions, and the foundation for frameworks (Django, Flask, data science libraries) later on. Advanced topics (decorators, generators, async, metaclasses, etc.) are intentionally left out of this first week — they matter, but they're part of the long-tail 80% that's far easier to pick up once these fundamentals are second nature.

## ✅ How to Use This Repo

1. Clone the repo:
   ```bash
   git clone https://github.com/Shiva-Kumar-S-M/python-practice.git
   cd python-practice
   ```
2. Work through each `dayN_...` folder in order.
3. Commit your practice files as you go — treat every commit as a checkpoint.
4. By Day 7, ship the capstone project as your proof of progress.

## 🛠️ Requirements

- Python 3.10+
- (Optional) A virtual environment: `python -m venv venv`
